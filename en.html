Four steps to a test installation

  1. Extract the package

    Download the ZIP and extract it into a dedicated application folder on the target system.

  2. Prepare the container

    For QNAP, enter the absolute package path in docker-compose.qnap.yml. Create a separate application; port 8092 must be available.

  3. Connect your LOGO!

    Open the local server address on port 8092. Set your own application password and enter your LOGO! credentials.

  4. Check the mapping

    Match measurement addresses and scaling to your own system. Test reading first; only change setpoints after verifying the mapping.

Requirements & test status

Docker with Compose or compatible QNAP Container Station, a modern browser and a reachable LOGO! web interface. Internet is needed to download the container image. Models, firmware and NAS versions still require validation.

Preparation package: not tested on a second QNAP or another LOGO!. No universal model compatibility claim. No Windows installer.
