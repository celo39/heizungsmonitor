Dans les captures supplémentaires, les informations privées ont été supprimées par des bandes opaques. Tous les autres pixels sont inchangés.

Quatre étapes pour une installation de test

  1. Extraire le paquet

    Télécharger le ZIP et l’extraire dans un dossier dédié sur le système cible.

  2. Préparer le conteneur

    Sur QNAP, indiquer le chemin absolu dans docker-compose.qnap.yml. Créer une application distincte ; le port 8092 doit être disponible.

  3. Connecter votre LOGO!

    Ouvrir l’adresse locale du serveur sur le port 8092. Définir votre mot de passe et saisir vos identifiants LOGO!.

  4. Vérifier les adresses

    Adapter les adresses et les facteurs de conversion à votre installation. Tester la lecture avant toute modification de consigne.

Prérequis et état des tests

Docker avec Compose ou QNAP Container Station compatible, navigateur récent et interface web LOGO! accessible. Internet est nécessaire pour télécharger l’image. Modèles, micrologiciels et versions NAS restent à valider.

Paquet préparatoire : non testé sur un second QNAP ou un autre LOGO!. Compatibilité universelle non garantie. Aucun installateur Windows.
