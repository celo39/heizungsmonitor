# Heizungsmonitor

Entwickler-Vorschau einer statischen Webseite. Sie verteilt das Container-Paket für den privaten Einsatz im eigenen lokalen Netzwerk.

Das Programm selbst läuft nach dem Download bei jedem Nutzer zu Hause, auf einer QNAP mit Container Station oder auf einem Rechner mit Docker. Diese Seite zeigt keine Live-Daten und verbindet sich nicht mit einer Heizung.

## Inhalt

- `index.html`, `fr.html`, `en.html` — die Seite auf Deutsch, Französisch und Englisch
- `downloads/` — Container-ZIP, deutsche Anleitung und SHA-256-Prüfsumme
- Download-Zähler über das GitHub-Release `v2026-10-18`
- Bewertungen als öffentliche GitHub-Meldungen mit dem Formular `bewertung`
- `images/` — Beispielaufnahmen, private Angaben sind geschwärzt

Eine Nutzungslizenz und Kontaktangaben sind noch nicht festgelegt. Das Programm wird ohne Garantie bereitgestellt.

## Veröffentlichung

Die Dateien sind für GitHub Pages gedacht. Im Repository unter Settings → Pages die Quelle `main` und den Ordner `/ (root)` wählen. Die Seite erscheint danach unter `https://<name>.github.io/<repository>/`.
